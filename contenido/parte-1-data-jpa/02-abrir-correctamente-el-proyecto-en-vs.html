2 Abrir el proyecto en VS Code

1. Ve a la carpeta donde hayas dejado el zip que se descargó. Clic derecho sobre el ZIP, Extraer todo. No trabajes dentro del ZIP.

2. Abre VS Code. En File > Open Folder > Abrir carpeta, selecciona la carpeta que has extraido.

3. Acepta la importación del proyecto Maven cuando se solicite y espera a que termine de descargar dependencias. La primera vez necesitas conexión a Internet.

Entender las carpetas que ya existen

  • pom.xml: la lista de dependencias y las reglas de construcción. Aquí añadimos dependencias si las necesitamos.
  • src/main/java: aquí va tu código Java.
  • src/main/resources: aquí van la configuración y los datos SQL de inicio.
  • ExamenApplication.java: clase de arranque. Su método main pone en marcha Spring.

Piensa en una mochila: las carpetas separan los cuadernos; pom.xml es la lista del material y la clase principal es el botón de encendido.
