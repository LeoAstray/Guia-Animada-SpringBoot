DependenciasMySQL Driver, Spring Data JPA, Spring Boot DevTools, Spring Web, Validation
Cada dependencia tiene su motivo. Spring Data JPA trae las entidades, los repositorios y Hibernate. MySQL Driver es el traductor entre Java y MySQL. Spring Web trae Spring MVC y el servidor Tomcat, para tener endpoints. Validation permite el @Valid de la ampliación (sección 28). DevTools reinicia la app al guardar.

En Spring Boot 4.1 el starter web se llama spring-boot-starter-webmvc (en apuntes antiguos verás spring-boot-starter-web).

spring.application.name=biblioteca

spring.datasource.url=jdbc:mysql://localhost:3306/biblioteca?createDatabaseIfNotExist=true&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
# Sin sesion abierta durante toda la peticion: asi el fallo LAZY es real y entendemos donde va @Transactional
spring.jpa.open-in-view=false
PropiedadPor qué
createDatabaseIfNotExist=trueSi la base biblioteca no existe, MySQL la crea al conectar. Evita el error «Unknown database».
ddl-auto=updateHibernate crea o ajusta las tablas y conserva los datos entre ejecuciones.
show-sql y format_sqlMuestran el SQL en la terminal. Imprescindible para contar consultas y cazar el N+1 (sección 27).
open-in-view=falseEvita que la sesión quede abierta durante toda la petición. Así el fallo LAZY es real y se entiende dónde va @Transactional.

Ajusta usuario, contraseña y puerto a los de tu MySQL.
